====================
API ENDPOINTS:
====================

Base URL: http://localhost:5000/api/bhuvan

All endpoints require authentication (JWT token)

1. GET /api/bhuvan/ndvi
   Query: latitude, longitude, startDate, endDate
   Purpose: Get NDVI (crop health) data

2. GET /api/bhuvan/soil-moisture
   Query: latitude, longitude, date
   Purpose: Get soil moisture data

3. GET /api/bhuvan/crop
   Query: latitude, longitude, season, year
   Purpose: Get crop classification data

4. GET /api/bhuvan/imagery
   Query: latitude, longitude, radius
   Purpose: Get satellite imagery metadata

5. GET /api/bhuvan/weather
   Query: latitude, longitude
   Purpose: Get weather data from Bhuvan

6. GET /api/bhuvan/lulc
   Query: latitude, longitude, year
   Purpose: Get land use/land cover data

7. GET /api/bhuvan/agricultural-data
   Query: latitude, longitude, startDate, endDate, season, year
   Purpose: Get comprehensive agricultural data (all in one)

====================
HOW TO USE:
====================

1. Start Backend Server:
   cd backend
   npm run dev

2. Test API (requires authentication):
   curl -H "Authorization: Bearer YOUR_JWT_TOKEN" \
     "http://localhost:5000/api/bhuvan/ndvi?latitude=17.3850&longitude=78.4867&startDate=2024-01-01&endDate=2024-03-31"

3. Run Python Data Collector:
   python bhuvan_data_collector.py
