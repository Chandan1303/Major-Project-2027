# India state and district directory

`india-states-districts.json` provides the state/union-territory and district choices used by the farm registration form and Flask validation.

- Data mirror: [KTBsomen/Indian-state-district-json](https://github.com/KTBsomen/Indian-state-district-json)
- Upstream reference named by the mirror: [Government of India directory](https://igod.gov.in/sg/district/states)

Review the upstream directory when updating this file, since administrative boundaries and names can change.
