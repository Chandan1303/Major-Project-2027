NEW FEATURES:
====================

1. ✅ State-Specific Variety Selection
   - Each state shows ONLY varieties that grow there
   - When user changes state, varieties auto-update
   - Example: Karnataka → Shows CoM 0265, Co 86032, etc.
            Maharashtra → Shows Co 86032, CoC 671, Co 775, etc.

2. ✅ New Variety Experiment Detection
   - If prev_year_yield = 0 or empty → Model knows it's NEW
   - Reduces confidence score automatically
   - Shows warning banner in results
   - Provides special recommendations

3. ✅ Smart Predictions
   - Normal variety: Higher confidence (85-95%)
   - New variety: Lower confidence (75-85%)
   - Adjusts yield prediction for experiments
