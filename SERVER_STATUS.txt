SugarYield AI local development status
======================================

This file records how to start the current Flask/Vite application. Server
processes are not assumed to be running; ports and network addresses depend on
the machine and the current session.

Backend API (Flask, port 5000), from the repository root:

    python run_backend.py

Frontend (Vite, port 5173), from a second terminal:

    cd frontend
    npm run dev

Open http://localhost:5173. The frontend's Vite configuration proxies /api to
the Flask API at http://127.0.0.1:5000. Check the API at
http://127.0.0.1:5000/api/health.

See HOW_TO_RUN.md for Python dependencies, environment setup, and optional
SQLite/MySQL configuration. Do not rely on old process IDs or LAN addresses.
